# Agentic RAG

> Aliases: 智能体RAG, Agent RAG, 自主检索RAG

## 定义

Agentic RAG 是一种将 LLM Agent 作为 RAG 系统控制器的范式。与传统的"检索-生成"单轮模式不同，Agentic RAG 允许智能体自主决定何时检索、检索什么以及如何综合多源信息。
