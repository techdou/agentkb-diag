# 大语言模型的知识边界：何时检索、何时依赖内部知识

> Kandpal N, Deng H, Roberts A, Wallace E, Raffel C (2023)

## Abstract

研究LLM内部知识边界对检索决策的影响。

## Key Claims

- <a id="claim_028"></a>**claim_028** (unsupported): 检索在任何情况下都能提升LLM的生成质量
- <a id="claim_029"></a>**claim_029** (supported): LLM已具备相关知识时检索可能降低生成质量

## Concepts

- Knowledge Boundary
- Retrieval Decision
- Parametric Knowledge
