# Sources

* [Dense Passage Retrieval：面向开放域问答的稠密检索方法 (2020)](/sources/source_001.md) - 提出DPR框架，使用双编码器架构将问题和段落分别编码到稠密向量空间中，在多个开放域问答基准上取得显著提升
* [检索增强生成：面向知识密集型 NLP 任务的神经方法 (2020)](/sources/source_002.md) - 提出RAG框架，将DPR检索与BART生成相结合的端到端模型
* [知识密集型 NLP 任务中的检索方法综述 (2021)](/sources/source_003.md) - 系统综述面向知识密集型NLP任务的检索方法，分为稀疏、稠密和混合三类
* [REALM：检索增强语言模型预训练 (2020)](/sources/source_004.md) - 将检索机制融入语言模型预训练过程，在预训练阶段学习知识检索
* [开放域问答系统中的检索方法评估 (2017)](/sources/source_005.md) - 系统评估开放域问答中的各类检索方法，提出DrQA系统
* [FiD：融合解码器——多检索段落的知识融合方法 (2021)](/sources/source_006.md) - 提出FiD架构，每个段落分别编码后解码器融合所有段落信息
* [RAG 中的评估指标与基准：系统综述 (2022)](/sources/source_007.md) - 系统综述RAG评估指标和基准数据集

* [知识检索在事实验证中的应用与挑战 (2018)](/sources/source_010.md) - 研究事实验证中的证据检索方法，构建FEVER数据集

* [引用忠实度：RAG 系统中的归因与可验证性 (2023)](/sources/source_013.md) - 研究RAG系统中的引用忠实度和归因问题，发现约30%引用不匹配
* [KG-RAG：结合知识图谱与向量检索的混合 RAG 框架 (2024)](/sources/source_014.md) - 结合知识图谱结构化查询与向量检索语义搜索的混合方法
* [MultiHop-RAG：面向多跳推理的 RAG 评估基准 (2024)](/sources/source_015.md) - 提出MultiHop-RAG评估基准测试多跳推理能力

* [Corrective RAG：面向检索噪声的纠正式 RAG 方法 (2024)](/sources/source_017.md) - 针对检索结果中噪声和无关信息进行纠错改进
